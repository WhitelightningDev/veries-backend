# veries-backend

Senior-style Python backend scaffold (FastAPI + `src/` layout).

## Quickstart

### 1) Install

```bash
python -m pip install -U pip
pip install -e ".[dev]"
```

### 2) Configure env

```bash
cp .env.example .env
```

### 3) Run

```bash
make dev
```

Open:
- `GET http://localhost:8000/api/health`

## Tests

```bash
make test
```

## Lint / format

```bash
make lint
make format
```
